# ศูนย์รวมแบบฝึกหัด — เตรียมสอบนักบินกองทัพเรือ

เว็บแอปรวมแบบฝึกหัดสำหรับเตรียมสอบนักบินกองทัพเรือ หน้าแรก (`/`) เป็นแดชบอร์ดรวมแบบทดสอบ กดเข้าไปเล่นแต่ละแบบทดสอบได้ที่ `/tests/<slug>`

แบบทดสอบที่มีตอนนี้:

- **คิดเลขในใจ** (`/tests/mental-math`) — โจทย์เลข 2-3 หลัก 50 ข้อ คละบวก ลบ คูณ หาร ยกกำลัง ถอดราก จับเวลาข้อละ 30 วินาที สุ่มใหม่ทุกครั้ง
- **บวกเลขสัญลักษณ์** (`/tests/symbol-addition`) — จำสัญลักษณ์แทนตัวเลข 10 ตัว (0-20) แล้วบวกเลขสะสมจากลำดับสัญลักษณ์ 32 ตัวที่สุ่มมา รอบละ 30 วินาที ทำทั้งหมด 5 รอบ ระบบตรวจว่าคำตอบตรงกับผลบวกสะสม ณ ตำแหน่งใดหรือไม่

ทุกแบบทดสอบมีระบบตรวจคะแนนและเฉลยรายข้อ/รายรอบให้ทันทีที่ทำเสร็จ

## เพิ่มแบบทดสอบใหม่ในอนาคต

โครงสร้างถูกออกแบบให้ต่อขยายง่าย:
1. เขียนตรรกะสุ่มโจทย์ไว้ใน `lib/<ชื่อไฟล์>.ts`
2. สร้างคอมโพเนนต์ UI ไว้ใน `components/<ชื่อ>.tsx`
3. สร้างหน้า route ที่ `app/tests/<slug>/page.tsx` ห่อด้วย `TestShell`
4. เพิ่มรายการลงทะเบียนใน `lib/tests.ts` เพื่อให้ขึ้นในแดชบอร์ดหน้าแรกอัตโนมัติ

## รันทดสอบในเครื่อง

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm run dev
```

แล้วเปิด http://localhost:3000

## Deploy ขึ้น Vercel

1. สร้าง repository บน GitHub แล้ว push โค้ดโปรเจกต์นี้ขึ้นไป:
   ```bash
   git init
   git add .
   git commit -m "init: navy pilot mental math trainer"
   git branch -M main
   git remote add origin <URL ของ repo คุณ>
   git push -u origin main
   ```
2. เข้า https://vercel.com แล้วกด **Add New... > Project**
3. เลือก repo ที่เพิ่ง push ขึ้นไป Vercel จะตรวจพบว่าเป็นโปรเจกต์ Next.js อัตโนมัติ (ไม่ต้องตั้งค่าอะไรเพิ่ม)
4. กด **Deploy** รอสักครู่ก็จะได้ลิงก์ `https://<ชื่อโปรเจกต์>.vercel.app` ใช้งานได้ทันที

หรือใช้ Vercel CLI:
```bash
npm i -g vercel
vercel
```

## ปรับแต่งความยาก / จำนวนข้อ / เวลา

แก้ไขได้ที่:
- `components/QuizApp.tsx` — ค่าคงที่ `TOTAL_QUESTIONS` (จำนวนข้อ) และ `TIME_PER_QUESTION` (วินาทีต่อข้อ)
- `lib/generateQuestions.ts` — ช่วงตัวเลขของแต่ละโจทย์ (บวก ลบ คูณ หาร ยกกำลัง ถอดราก)
- `lib/symbolTest.ts` — ค่าคงที่ `LEGEND_SIZE` (จำนวนสัญลักษณ์), `VALUE_MIN`/`VALUE_MAX` (ช่วงตัวเลข), `ROUND_LENGTH` (จำนวนสัญลักษณ์ต่อรอบ), `TOTAL_ROUNDS` (จำนวนรอบ), `ROUND_TIME` (วินาทีต่อรอบ)
